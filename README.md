# Git a GitHub od základov

Webová verzia prezentácie o Gite a GitHube. Statická stránka (HTML, CSS, JavaScript), žiadny build ani závislosti.

## Súbory

- `index.html` – obsah stránky
- `styles.css` – vzhľad
- `script.js` – mapa kapitol, kopírovanie príkazov a kvíz

## Nasadenie na GitHub Pages

1. Nahraj tieto súbory do koreňa repozitára (vetva `main`).
2. Na GitHube otvor **Settings → Pages**.
3. V časti **Build and deployment** vyber **Deploy from a branch**, vetvu `main` a priečinok `/ (root)`.
4. Ulož. O minútu bude stránka na adrese `https://<meno>.github.io/<repozitar>/`.

## Pred zverejnením

- Odkaz na Google formulár: v `index.html` vyhľadaj `DOPLN-ODKAZ-NA-FORMULAR` a nahraď celú adresu v `href`.
